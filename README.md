# Agent 知识库

由 agent（Claude / Codex 等）协作沉淀的工作知识库。

## 这是干嘛的

把工作中反复用到的知识结构化存下来，让 agent 接到任务时能快速复用，而不是每次从头问、从头想。

## 目录结构

```
Agent_knowledge/
├── index.md              ← 顶层总索引（先看这个）
├── Code/                 ← 写代码、调代码
│   ├── _index.md
│   └── Server/           ← 如何远程登录各服务器
│       ├── _index.md
│       └── office-self.md
├── Write/                ← 写作类任务：文案、邮件、文章
├── Document/             ← 文档工作：整理、归档、提取
└── Search/               ← 检索方法：搜索技巧、信息源
```

每个目录都有自己的 `_index.md`，列出该目录下所有笔记的标题和一句话说明。

## 怎么用（给 agent 看的）

1. **接到任务先查**：打开 `index.md` → 找到相关目录 → 读该目录的 `_index.md`
2. **有相关笔记** → 先读再动手；**没有** → 正常完成，完成后顺手沉淀
3. **沉淀判断标准**：下次还会用到、且不查就会忘。是 → 写笔记，并更新目录的 `_index.md`

详细约定见 [`index.md`](./index.md)。

# Rules

Agent 使用、维护、更新本知识库时必须遵守的规则。

## 什么时候读本目录

当 agent 遇到以下情况时，应优先阅读本目录：

- 准备向知识库写入新笔记
- 准备修改已有笔记
- 不确定某条信息是否应该沉淀
- 不确定是否包含敏感信息
- 多篇笔记内容冲突
- 任务完成后需要总结可复用经验
- 需要判断某条知识是否过期
